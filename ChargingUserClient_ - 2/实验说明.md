# 东软电动汽车充电桩应用管理平台用户端

本项目根据 `01.项目说明书-东软电动汽车充电桩应用管理平台(2).doc` 与 `01需求矩阵-第16组-安铭浩(7).xls` 中的用户端需求实现，采用 C++、Qt 6、Qt Widgets 与 SQLite 数据库完成。

## 运行环境

- Ubuntu 22.04
- Qt 6.2 及以上
- Qt Creator 或命令行 `qmake6 + make`

## 编译方式

```bash
qmake6 ChargingUserClient.pro
make
./ChargingUserClient
```

## 用户端功能覆盖

1. 账号功能：手机号注册、登录、7天免登录、找回密码、修改密码、注销。
2. 校验规则：手机号、4位验证码、8位密码、昵称格式均按需求矩阵实现。
3. 个人资料：展示手机号、昵称、头像、账号状态，支持选择本地头像和修改昵称。
4. 钱包功能：余额查询、充值、充值流水和充电扣费流水查询。
5. 附近充电站：按区域和地址关键字查询，显示站名、电价、电桩数量、空闲数量、距离、推荐分。
6. 充电站详情：展示站内电桩编号、类型、状态、功率、累计次数、累计时长。
7. 路线导航：根据所选站点和出行方式生成腾讯地图路线链接，并调用系统浏览器打开。
8. 充电流程：选择空闲电桩后，完成预约、充电、计费、结算流程。
9. 异常处理：支持模拟电桩故障，生成异常待结算订单并提示用户。
10. 智能推荐：根据演示数据中的推荐分优先展示低拥堵、高空闲率站点。

## 工程结构

- `mainwindow.ui`：使用 Qt Designer `.ui` 文件设计全部界面。
- `mainwindow.h/.cpp`：用户界面、信号槽连接和页面跳转。
- `databasemanager.h/.cpp`：SQLite 建表、演示数据、用户、钱包、电站、电桩、订单与流水管理。
- `chargingworker.h/.cpp`：充电过程后台线程模拟，通过信号向界面发送进度。
- `resources.qrc`：Qt 资源文件，管理图标和 QSS 样式。
- `resources/styles/userclient.qss`：界面美化样式。

## 说明

当前版本聚焦完成“用户端”部分。由于服务器端和数据库端不是本次交付重点，用户端使用本地 SQLite 模拟服务端数据读写，便于单独编译、演示和验收。
